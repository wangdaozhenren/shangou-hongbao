# 闪购即时零售红包助手 · 平台规则与叠加指南

> 覆盖平台：美团闪购、淘宝闪购、饿了么超市（30分钟达即时零售）。

## 一、各平台红包规则

### 美团闪购
- **领取条件**：新客首单立减、老客神价频道券、超级品牌日/零售品牌日专属券
- **使用门槛**：多为满减券（如满39减X），限超市/便利店/药店等闪购商家；药品、烟草等品类受限
- **有效期**：券码多为当日或2~3天有效，品牌日活动限指定日
- **是否可叠加**：券可与门店满减叠加；神价频道为一口价，不与大额券重复

### 淘宝闪购（淘宝小时达/淘鲜达）
- **领取条件**：新客首单券、老客爆品好价券、领免单卡活动
- **使用门槛**：限小时达/闪购商品，满减门槛因品类而异
- **有效期**：券码短期有效，免单卡活动限当期
- **是否可叠加**：券与店铺满减、淘宝红包可叠；免单卡为抽奖/返券性质

### 饿了么超市
- **领取条件**：新客券、老客超市满减券、夜宵/应急时段券
- **使用门槛**：限超市便利类闪购订单，常见满减门槛
- **有效期**：券码当日或数天有效
- **是否可叠加**：券与门店满减可叠，与外卖红包视活动互斥

## 二、红包叠加逻辑

- **叠加顺序**：平台闪购券 → 门店/品类满减 → 支付优惠
- **凑单技巧**：满减券差一点门槛时，加包纸巾/水凑到门槛更划算
- **急用领券**：闪购主打30分钟达，急用先领券再下单
- **夜间应急**：深夜买药、日用品，领夜间券下单

## 三、品类专属知识要点

### 3.1 30分钟达 vs 次日达（决策核心）
- **闪购30分钟达**：贵、快、即时，急用（缺药、缺日用品、深夜应急）选它
- **次日达/囤货**：便宜、慢、批量，不急的日用品走次日达或大促囤货更省
- 别把急用的闪购当日常囤货渠道——为"快"付的溢价不划算
- 不急的纸巾洗衣液等囤货，等次日达或电商大促

### 3.2 免邮/起送门槛
- 闪购有起送价和满免邮门槛，差几块就凑单到门槛
- 凑单选本就用得上的小东西，别为免邮买不需要的
- 配送费、打包费一般不抵券，凑单时看结算总价

### 3.3 夜间配送加价
- 深夜、凌晨时段部分平台有夜间配送费/加价，券一般不抵这部分
- 夜间运力紧张，预计送达时间可能偏长，急用先看时效
- 夜间券有时力度大，但要算上夜间配送费才是真实花费

### 3.4 特殊品类与售后
- 烟草、处方药不参与或不可用券；酒类、药品按相关规定购买
- 生鲜、冷链品收货当场验货，化冻/破损/错发在平台申请售后
- 闪购商品退换按平台规则，生鲜类不支持无理由

## 四、新客与老客区别

- **新客专享**：首单大额立减，力度最大，一个账号一次
- **老客可领**：神价频道、品牌日券、爆品好价券
- **新老客通用**：平台通用满减券、免单卡抽奖活动
- 新客券用在第一次闪购的急用单上最划算

## 五、避坑指南

1. **急用才用闪购**：闪购溢价买"快"，日常囤货走次日达更省
2. **配送费不抵券**：别以为无门槛券免邮，配送费另算
3. **夜间加价**：深夜单要算夜间配送费，券不一定抵
4. **为凑单乱买**：凑单选用得上的，别为免邮买不需要的
5. **免单卡别当真**：赢免单/免单卡是随机活动，不保证必中，理性参与
